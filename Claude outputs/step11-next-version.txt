=========================== THE THREE THINGS TO SAY ===========================

1. The graph grew. OBL-12 exists because an expert created it through an event.
   The JSON on disk is unchanged. v3's penalty change links to it and propagates
   through the edge the expert added.

2. Human decisions carry forward. Anything Dana approved or corrected in v2 is in
   the log when v3 runs, and a correction on the same edit or the same paragraph
   text is applied before the model is asked.

3. Finality was detected from the text. The header says final, but the model was
   never told to trust it; it judged from the caption, "are adopted", and the
   effective-date sentence, and the eval compares its majority answer to the header.

recorded with the prefilled values. Changing them before loading v3 needs an API
key. In production the cache would be per company and always live; here it is a
reproducibility device for reviewers without a key.
